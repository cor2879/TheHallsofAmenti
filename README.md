# The Halls of Amenti

A shared library for experience, sources, and inquiry.

This repository is the home for developing The Halls of Amenti: a knowledge
commons connecting a core reference library with community contributions through
source-linked topic discovery.

## Status

Project planning. The design foundation and first prototype scope are being
prepared for review. No application or hosted service has been implemented.

See the [pull requests](https://github.com/cor2879/TheHallsofAmenti/pulls) for
proposed work.
